# Custom Workspace Rules

## Changelog Policy
- Always maintain a `CHANGELOG.md` file in the root of the project adhering to the [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format and standard.
- Document all notable changes, additions, removals, and fixes under the appropriate version headers (`Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, `Security`).
